An honest note

Why you'll see a warning.

Apple charges developers $99 a year to sign and approve apps, and Microsoft's code-signing certificates cost money too. SVX is a free beta, so it is not signed by Apple or Microsoft. If you download the file with your browser, your computer asks you to confirm the first time you open it. On a Mac, if you use the Terminal command above, macOS has nothing to ask: the app is the same, but it is not marked as downloaded from the internet.

The warning means the system doesn't recognise the publisher. It's a good moment to check the file is the one we published: compare its checksum with the one on this page before you continue.

The macOS and Windows betas are available. The Linux tab shows what to expect once that build exists.

  1. Open the .dmg and drag SVX into Applications.
  2. Open SVX. macOS says it can't verify it. Close the message.
  3. Open System Settings → Privacy & Security. Scroll down and click Open Anyway next to SVX, then confirm.
  4. On older macOS versions: Control-click SVX in Applications, choose Open, then Open again.
  5. If macOS says SVX is "damaged", don't move it to the Bin. That's the same check. Open Terminal and run xattr -cr "/Applications/Secure Verified Exchange.app", then open SVX again.
  6. You only need to do this once. Or skip all of it: curl -fsSL https://getsvx.me/install.sh | sh installs SVX with no prompt.
  1. Open SVX-beta-Windows.exe from your Downloads folder.
  2. Windows shows “Windows protected your PC”. Click More info.
  3. It says “Unknown publisher”, because the beta isn't signed. Click Run anyway, then follow the installer. It installs for your user only and doesn't need an administrator.
  4. Your browser may also warn that the file isn't commonly downloaded. Choose Keep (in Edge: the … menu, then Keep).
  5. SVX confirms it's you with Windows Hello (face, fingerprint or PIN). If you have none, set up a PIN in Settings → Accounts → Sign-in options.
  6. The Windows Hello prompt can open behind the SVX window. If you don't see it, click Windows Security in the taskbar.
  7. You only need to do the warning steps once. SVX updates itself after that.
  1. Install the package, for example: sudo apt install ./SVX-beta-Linux.deb
  2. Open SVX from your applications menu.
  3. Note: SVX on Linux refuses to show view-only files, because Linux has no reliable way to keep a window out of screenshots.

Verify your download

Check the checksum.

Run the command for your system in the folder where you saved the file. The result should match the SHA-256 shown on the download card exactly.

macOS · Terminal

shasum -a 256 SVX-beta-macOS.dmg

Windows · PowerShell

Get-FileHash .\SVX-beta-Windows.exe -Algorithm SHA256

If it doesn't match, don't open the file. Download it again from this page.
