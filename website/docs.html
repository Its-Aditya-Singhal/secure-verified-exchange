Docs & FAQ

Using SVX.

The basics of sealing, opening and revoking, and answers to common questions.

On this page

Install Send a file Open a file Revoke access View-only files FAQ

Install

Download SVX for Windows 10 and 11, or a Mac with an Apple chip (Linux is coming). Check the SHA-256 checksum, then follow the first-launch steps, since the beta isn't signed by Apple or Microsoft. Then create your account in the app: continue with Google, or use your email address and a password. There is nothing to sign up for on this website.

Send a file

  1. Open SVX and choose the file you want to send.
  2. Add the people who should be able to open it, by the email address they use for SVX.
  3. Pick the rules: approve each open (on by default), one open per person (on by default), an expiry date, view-only.
  4. Seal it. SVX encrypts and signs the file and splits its key. Send the .svx file any way you like: email, chat, a USB stick.

Open a file

Double-click the .svx file. SVX checks the sender's signature and that the file is addressed to you, then asks the service for its half of the key. If the sender asked to approve opens, they get a request in their app; once they approve, the file opens. Example: Bob opens the report Alice sealed for him.

Revoke access

Revoke a recipient's access in SVX and the file won't open for them again. Revocation stops future access. It cannot take back a file someone already opened.

View-only files

View-only blocks saving, copying and screenshots in the app. It cannot stop someone photographing their screen.

  • macOS: built in and tested.
  • Windows: built in and tested.
  • Linux: SVX refuses to show view-only files.

FAQ

Do I need an account on this website?

No. This website is only for information and downloads. There's nothing to sign up for or log in to here.

Does this website ever see my files?

No. Files and keys never touch a browser. Sealing and opening happen in the SVX desktop app.

Can someone open an SVX file without the app?

No. Opening needs SVX software, the recipient's verified sign-in and both halves of the key. Without all three, a copy of the file is just encrypted data.

Does the person I send to need SVX too?

Yes. They install SVX and create an account with the email address you send to. That account is how SVX checks it's really them.

What happens if I revoke access after someone has opened the file?

Revocation stops future access. It cannot take back a file someone already opened, so they've already seen what they saw.

Does view-only stop screenshots?

View-only blocks saving, copying and screenshots in the app. It cannot stop someone photographing their screen.

On macOS and Windows it is built in and tested. SVX on Linux will refuse to show view-only files.

Why does my computer warn me when I first open SVX?

The beta isn't signed by Apple (that costs $99 a year), so macOS treats it as from an unidentified developer. The one-line Terminal install on the download page avoids the warning. See the steps to continue.

How do I know my download is genuine?

Compare the file's SHA-256 checksum with the one on the download page. After installing, updates are verified with our own signing keys.

What is post-quantum hybrid encryption?

It combines a well-established encryption method with a newer one designed to resist future quantum computers. Someone would have to break both to read your file.

Is the file format documented?

Yes. The .svx container has a written specification and test vectors, so it can be reviewed independently of the app.

Can SVX read my files?

No. The SVX service holds only one half of each file's key and never receives the file itself, or its name. It does see who sent a file to whom and when it was opened, because that is how approval and revocation work.

How do I contact SVX?

For help or questions, write to support@getsvx.me. To report a security problem, write to security@getsvx.me (see the security page). Please don't put passwords, recovery codes or file contents in an email.

I didn't get the sign-up code email. What now?

Check your Spam or Junk folder. The first email from a new sender often lands there. If you find it, open it and choose "Not spam" so later emails reach your inbox. If nothing arrives after a few minutes, use "Send a new code" in the app. The code expires after 10 minutes and works once.

Does this site use cookies or analytics?

No analytics and no tracking cookies. If you switch the theme, that choice is saved in your own browser only.

Is SVX finished?

No, SVX is in beta. Expect rough edges, and read the threat model and limits before relying on it.
