File names and contents never reach the service, so they can't appear here. Close the Terminal window (or press Ctrl-C there) to end this session.

Suspend

They can't sign in, nobody can send them files, and files they sent stop opening. You can undo this. They get an email (with the reason, if you give one).

Lift the suspension

Everything works again for them, including files they sent. They get an email saying so.

Delete account

Erases the account, its keys, every file it sent and its own activity log. This cannot be undone. They get an email (with the reason, if you give one). Type the email address to confirm.
